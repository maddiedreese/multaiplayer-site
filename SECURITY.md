# Security Policy

This repository contains the public website, release-download discovery, Apple universal-link association, and private-invitation landing for multAIplayer. Reports are welcome for the current `main` branch and the deployed site.

For website vulnerabilities, use this repository’s [GitHub private vulnerability reporting](https://github.com/maddiedreese/multaiplayer-site/security/advisories/new). For desktop or relay vulnerabilities, use the [application repository’s private reporting](https://github.com/maddiedreese/multAIplayer/security/advisories/new). If those channels are unavailable, email [maddie@maddiedreese.com](mailto:maddie@maddiedreese.com). Do not open a public issue with vulnerability details.

Include the affected URL, commit or deployment time, reproduction steps using dummy values, expected and actual behavior, and any relevant browser or platform version. The project aims to acknowledge reports within three business days and provide a status update at least every seven days while a report remains open. Please allow up to 90 days for coordinated disclosure unless active exploitation or another urgent risk requires a shorter timeline.

Never send a complete invitation URL or fragment, a real credential, private room content, private repository material, or an unreviewed diagnostic bundle. The maintainer will never ask for a complete invite link. If one is exposed, invalidate it and create a replacement rather than forwarding it again.

The application repository’s [threat model](https://github.com/maddiedreese/multAIplayer/blob/main/docs/threat-model.md) defines intended security properties, exclusions, relay-visible metadata, and residual risks. Marketing summaries and this policy do not expand those guarantees.
